# 지니뷰티랩 챌린지 자동화 키트

9/1 라이브 챌린지에서 배포하는 **블로그 자동화**, **카드뉴스·인스타그램 자동화** 설치 키트 모음입니다.
수강생은 이 저장소를 그대로 다운로드(zip)해서 원하는 도구 폴더 하나만 열고, 안의 `README.md`를 따라가시면 됩니다.

## 구성

| 폴더 | 내용 |
|---|---|
| [`카드뉴스_세팅용/`](./카드뉴스_세팅용) | 블로그 글 → 인스타 카드뉴스 자동 생성·발행 키트 (Mac 전용 설치) |
| [`블로그자동화_세팅용/`](./블로그자동화_세팅용) | 키워드 → 블로그 글 초안·발행 대시보드 키트 (Mac·Windows 둘 다) |
| [`설치가이드_PDF/`](./설치가이드_PDF) | 두 키트의 인쇄용 설치 안내서 PDF |

## 각 키트 안에 있는 것

- `설치.command` / `설치.bat` — 더블클릭 한 번으로 필요한 프로그램 설치
- `README.md` — 비전문가 눈높이의 단계별 설치·사용 안내서 (PDF와 동일한 내용)
- `.claude/skills/설치-도우미/` — Claude Code로 이 폴더를 열고 "설치해줘"라고 말하면, 클로드가 대화로 설치를 대신 진행해주는 스킬

## 학생 안내 순서 (추천)

1. 이 저장소를 zip으로 다운로드해서 압축 해제
2. 배우는 도구의 폴더로 이동 (`카드뉴스_세팅용` 또는 `블로그자동화_세팅용`)
3. 그 폴더 안 `README.md`를 먼저 읽거나, 같은 폴더에서 Claude Code를 열고 "설치해줘"라고 말하기
4. 막히면 `설치가이드_PDF/`의 PDF를 참고하거나 화면을 캡쳐해서 AI에게 물어보기

## 주의

- 각 키트의 `config.json` / `.env.example`은 항상 빈 템플릿입니다. 실제 계정 정보(텔레그램 봇 토큰, 네이버 블로그 ID, 클로드 토큰 등)는 본인 것만 본인 폴더에 입력하세요.
- 이 저장소는 비공개입니다. 배포 시 학생에게는 zip 다운로드 링크로 공유합니다.
