# 블로그 글 하나로 인스타까지 — 설치 안내서

**컴퓨터를 잘 몰라도 괜찮습니다.**
이 안내서는 명령어를 한 줄도 안 치는 걸 목표로 만들었어요.
파일을 더블클릭하는 것만 하시면 됩니다.

---

## 이게 뭘 해주나요

블로그에 글을 하나 올리면, 컴퓨터가 알아서 이렇게 합니다.

```
블로그에 글 발행
      ↓
그 글을 읽고 인스타 카드 6~8장을 그림
      ↓
카드가 텔레그램으로 폰에 도착
      ↓
내가 보고 [올리기] 를 누르면
      ↓
컴퓨터가 인스타에 올려줌
```

원장님이 하실 일은 **블로그 글 하나**와 **버튼 한 번**입니다.

> **버튼을 왜 남겨뒀냐면요.**
> AI가 가끔 없는 이야기를 지어냅니다.
> 사람이 한 번도 안 보고 올라가면 그게 그대로 광고가 돼요.
> 3초만 눈으로 훑어주시면 됩니다.

---

# 0단계 · 먼저 아셔야 할 것 세 가지

## ① Claude(클로드)가 뭔가요

**글을 써주는 AI입니다.** 챗지피티 같은 거예요.

우리는 그중에서도 **Claude Code(클로드 코드)** 라는 걸 씁니다.
이건 좀 달라요. 대화창이 아니라 **원장님 컴퓨터 안에서 일을 하는** 클로드입니다.

쉽게 말하면 이렇습니다.

| | 하는 일 |
|---|---|
| 보통 클로드 | 물어보면 답을 화면에 써줌 |
| **클로드 코드** | 물어보면 **컴퓨터에서 직접 일을 해줌** |

우리가 시킬 일은 이겁니다.
"블로그 글을 읽고 카드 문구를 만들어서 파일로 저장해줘."

그건 대화창에서는 안 됩니다.
컴퓨터 안에서 해야 하는 일이라 클로드 코드를 씁니다.

**무섭게 생겼지만 무서운 거 아닙니다.**
검은 화면이 뜨는데, 원장님이 거기에 뭘 치실 일은 없어요.
설치할 때 딱 한 번 로그인만 하시면 됩니다.

## ② 돈이 듭니다 ★ 이건 꼭 알고 시작하세요

**클로드는 유료입니다. 한 달에 약 $20(미국 돈)입니다.**
우리 돈으로 3만원 좀 안 돼요.

**이게 없으면 아무것도 안 돌아갑니다.** 설치를 해도 소용없어요.
수강료에 포함돼 있지 않습니다. 원장님이 따로 결제하시는 겁니다.

**해외결제라 카드가 막힐 수 있어요.**
이게 제일 흔한 막힘입니다. 미리 알려드릴게요.

- 카드사 앱에 들어가서 **"해외결제 허용"** 을 켜두세요
- 그래도 안 되면 다른 카드로 해보세요
- 그래도 안 되면 단톡방에 말씀해 주세요

## ③ 컴퓨터가 켜져 있어야 합니다

이건 **원장님 컴퓨터에서 도는 프로그램**이에요. 인터넷 어딘가에 있는 게 아닙니다.

컴퓨터가 꺼져 있으면 그 시간엔 아무 일도 안 일어납니다.
노트북이면 뚜껑을 닫아두셔도 안 돼요.

**필요한 것 정리**

- [ ] 노트북이나 데스크탑 (맥·윈도우 둘 다 됩니다. 폰만으로는 안 돼요)
- [ ] 클로드 유료 구독 (월 $20)
- [ ] 네이버 블로그 계정 (글이 1개 이상 올라가 있어야 해요)
- [ ] 텔레그램 앱 (카드를 폰으로 받는 용도)
- [ ] 시술 사진 6~10장

# 1단계 · 설치하기

## 윈도우를 쓰신다면 — 이것부터 하세요 ★

압축을 **풀기 전에** 해야 합니다. 순서가 중요해요.

1. 받으신 **zip 파일에 오른쪽 클릭**
2. **속성** 클릭
3. 맨 아래 **"차단 해제"** 에 체크
4. **확인**
5. 그다음에 압축 풀기

이걸 안 하시면 윈도우가 "위험한 파일"이라고 막습니다.
체크 하나로 그게 다 사라져요.

> 압축을 풀 때는 꼭 **"압축 풀기"** 를 쓰세요.
> zip 안에서 파일을 바로 더블클릭하면 안 됩니다.

## 설치 파일 더블클릭

| 쓰시는 것 | 더블클릭할 파일 |
|---|---|
| 맥 | `설치.command` |
| 윈도우 | `설치.bat` |

검은 창이 뜨고 글자가 주르륵 올라갑니다. **정상입니다.**
처음엔 5~10분쯤 걸려요. 인터넷에서 필요한 걸 받아오거든요.

**그동안 창을 닫지 마세요.** 그냥 두고 딴 일 하시면 됩니다.

## 맥에서 "확인되지 않은 개발자" 가 뜨면

한 번은 뜹니다. 처음 한 번만요.

**맥 사양이 최신(세쿼이아 이상)이면**
1. 시스템 설정 열기
2. **개인정보 보호 및 보안** 클릭
3. 아래로 쭉 내리기
4. **"그래도 열기"** 버튼 클릭

**그 아래 사양이면**
1. `설치.command` 에 **오른쪽 클릭**
2. **열기** 클릭
3. 다시 뜨는 창에서 또 **열기**

어느 쪽인지 모르시겠으면 위쪽부터 해보세요. 없으면 아래쪽입니다.

## 윈도우에서 파란 창이 뜨면

"Windows의 PC 보호" 라고 나오면
**추가 정보** → **실행** 을 누르시면 됩니다.

0단계의 "차단 해제"를 하셨으면 이 창은 안 뜹니다.

---

# 2단계 · 클로드 로그인 (한 번만)

설치가 끝나면 화면에 이런 게 나옵니다.

> 클로드에 로그인해 주세요. 브라우저가 열립니다.

1. 인터넷 창이 저절로 열려요
2. 클로드 계정으로 로그인하세요 (아직 없으면 여기서 만드시면 됩니다)
3. **"허용"** 같은 버튼이 나오면 누르세요
4. 검은 화면에 글자를 붙여넣으라고 하면, 인터넷 창에 나온 걸 복사해서 붙여넣으세요

**붙여넣기는 이렇게 하세요.**
- 맥: `Command + V`
- 윈도우: 검은 창 안에서 **오른쪽 클릭 한 번** (그게 붙여넣기예요)

이건 처음 한 번만 하시면 됩니다.

---

# 3단계 · 내 정보 넣기

설치가 끝나면 **설정 화면이 저절로 열립니다.**
인터넷 창처럼 생긴 화면이에요. 거기서 채우시면 됩니다.

| 칸 | 뭘 넣나요 |
|---|---|
| 블로그 주소 | `blog.naver.com/abc123` 이면 → `abc123` |
| 인스타 아이디 | `@우리샵` |
| 샵 이름 | 카드 아래에 들어갈 이름 |
| 카드 색 | 색깔 동그라미를 눌러서 고르시면 돼요 |
| 사진 | 파일을 끌어다 놓으시면 됩니다 |

**사진은 두 종류를 넣어주세요.**

| 어떤 사진 | 몇 장 |
|---|---|
| 샵 인테리어, 작업대, 도구 **(얼굴 없이)** | 6~10장 |
| 원장님이 나온 사진 **(얼굴 나와도 됨)** | 3~6장 |

매일 **가장 오래 안 쓴 사진부터** 돌아가며 씁니다.
같은 사진이 연달아 안 나와요.

---

# 4단계 · 텔레그램 연결

카드를 폰으로 받기 위한 설정입니다. 5분이면 됩니다.

1. 폰에서 **텔레그램** 앱을 깔고 가입하세요
2. 검색창에 **@BotFather** 를 치세요 (아빠 로봇이라는 뜻이에요)
3. 대화를 시작하고 **`/newbot`** 을 보내세요
4. 이름을 정하라고 하면 아무거나 정하세요 (예: 우리샵카드)
5. 그러면 **길고 이상한 글자 덩어리**를 하나 줍니다. 그게 열쇠예요
6. 그 글자를 통째로 복사해서 **설정 화면의 "텔레그램 열쇠"** 칸에 붙여넣으세요
7. 방금 만든 로봇과의 대화방을 열고 **아무 말이나 한 번 보내세요** (예: 안녕)
8. 설정 화면에서 **연결 확인** 을 누르세요

"연결됐어요" 가 뜨면 끝입니다.

> 텔레그램을 안 쓰고 싶으시면 이 단계를 건너뛰셔도 됩니다.
> 카드는 컴퓨터의 `output` 폴더에 그대로 저장돼요.

---

# 5단계 · 테스트

설정이 다 끝났으면 한 번 돌려봅시다.

**`테스트.command`** (윈도우는 `테스트.bat`) 를 더블클릭하세요.

1~2분 뒤에
- `output` 폴더에 카드가 생기고
- 텔레그램으로 폰에 도착합니다

카드가 왔으면 성공입니다. 🎉

이제부터는 **매일 아침 9시 10분에 저절로** 돌아갑니다.
블로그에 새 글이 없는 날은 아무 일도 안 일어나요.

---

# 카드 문구를 고치고 싶으면

**`카드 글씨수정`** 을 더블클릭하세요.

- 인터넷 창에 편집기가 열리고 최근에 만든 카드 문구가 보입니다
- 고치면 옆에 미리보기가 바로 바뀌어요
- **저장** 을 누르면 이미지가 다시 만들어집니다
- 다 하셨으면 검은 창에서 `Ctrl + C`

**폰에서도 고칠 수 있어요.**
컴퓨터에서 편집기를 켜두면 검은 창에 주소가 하나 뜹니다.
같은 와이파이에서 폰 인터넷 창에 그 주소를 넣으시면 돼요.

---

# 인스타까지 자동으로 올리려면

**W3_인스타 폴더의 3번 문서**를 보세요.

텔레그램에서 **[올리기]** 버튼을 누르면 컴퓨터가 인스타에 대신 올려줍니다.

> ⚠️ 다만 이건 **인스타 약관상 위험이 있어요.** 계정이 정지될 수 있습니다.
> 3번 문서를 꼭 먼저 읽어주세요.
> 위험이 부담되시면 거기 적힌 **예약 발행**을 쓰시면 됩니다. 위험이 전혀 없어요.

# 잘 안 될 때

## 제일 먼저 해보실 것

**설치 파일을 다시 더블클릭하세요.**
여러 번 누르셔도 안전합니다. 넣어둔 사진이나 설정은 안 지워져요.

대부분은 인터넷이 잠깐 끊긴 거라 다시 하면 됩니다.

## 그래도 안 되면

| 이런 화면이 나오면 | 이렇게 하세요 |
|---|---|
| "인터넷을 확인해 주세요" | 와이파이 확인하고 다시 더블클릭 |
| "클로드 로그인이 필요해요" | 2단계를 다시 하세요 |
| "새 글 없음" | 정상입니다. 블로그에 새 글이 없으면 안 만들어요 |
| 컴퓨터가 꺼져 있었음 | 그날은 건너뜁니다. 테스트 파일로 직접 돌리세요 |
| 폴더를 옮겼더니 안 됨 | 설치 파일을 한 번 더 더블클릭 |

## 그 외 전부

**화면을 캡쳐해서 AI에게 붙여넣고 "이거 왜 이래?" 라고 물어보세요.**

이게 진심입니다. 대부분 그걸로 풀려요.

설치가 막히면 **자세한 기록을 자동으로 복사해둡니다.**
AI 채팅창에 그냥 붙여넣기(`Ctrl+V` / `Cmd+V`) 하시면 됩니다.

그래도 안 되면 화면을 캡쳐해서 단톡방에 올려주세요.

# ⚠️ 올리기 전에 꼭 확인

AI가 만든 문구라 가끔 틀립니다.
**인스타에 올리기 전에 한 번 읽어보세요.**

- 우리 동네가 아닌 지역 이름이 들어갔는지
- 없었던 일이 사실처럼 쓰였는지
- 우리 샵 숫자를 지어냈는지

그대로 올리면 허위광고가 됩니다.
3초면 봅니다. 꼭 보세요 🙏
