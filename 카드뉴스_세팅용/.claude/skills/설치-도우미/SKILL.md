# 설치-도우미 (카드뉴스/인스타그램 자동화)

수강생이 이 폴더 안에서 Claude Code를 열고 "설치해줘" 같은 말을 하면, README.md를 읽으라고 하지 말고 **아래 순서를 직접 실행**한다. 매 단계 끝나면 다음으로 넘어가기 전에 결과를 짧게 보고한다.

## 0. 안전 원칙 (항상 지킬 것)

- **반드시 이 스킬 폴더의 조상 폴더(카드뉴스_세팅용) 안에서만** 명령을 실행한다. 시작하기 전에 `pwd`로 현재 위치가 이 키트 폴더인지 확인하고, 아니면 `cd`로 이동한 뒤 진행한다.
- `~/cardnews`, 다른 학생의 폴더, 시스템 폴더 등 이 키트 밖은 **절대** 건드리지 않는다.
- 학생이 입력하는 텔레그램 토큰 등 비밀값은 **이 폴더의 `config.json`에만** 쓴다. 채팅에 그대로 다시 출력할 때는 앞 몇 글자만 보여주고 나머지는 마스킹한다(예: `1234567:AB••••••`).
- 어떤 단계든 실패하면 원인과 해결법을 바로 말해주고 멈춘다 — 이유 없이 다음 단계로 넘어가지 않는다.

## 1. 사전 확인

```bash
node -v
command -v claude && claude --version
```
- Node.js 없으면: "https://nodejs.org 에서 LTS 버전을 설치하고 다시 말씀해 주세요"라고 안내하고 멈춘다.
- Claude Code(`claude` 명령) 없으면: 이미 이 스킬이 실행되고 있다는 건 Claude Code가 있다는 뜻이므로 보통 이 체크는 통과한다. 혹시 실패하면 안내만 하고 멈춘다.

## 2. 패키지 설치

이 키트 폴더 안에서:
```bash
npm install --silent
npx playwright install chromium
```
설치 중 실패하면 에러 메시지를 그대로 보여주고 인터넷 연결부터 확인하도록 안내한다.

## 3. 정보 수집 (한 번에 하나씩, 대화로)

`config.example.json`을 참고해서 아래 항목을 **순서대로 하나씩** 물어본다. 한꺼번에 묻지 말 것 — 비전문가에게는 부담스럽다.

1. **블로그 아이디** — "네이버 블로그 주소가 blog.naver.com/OOO 라면, OOO 부분만 알려주세요"
2. **인스타그램 아이디** — "@" 포함해서
3. **샵 이름** — 카드 하단에 들어갈 이름
4. **브랜드 색상** — "카드에 쓸 메인 색이 있으실까요? 없으면 기본값(로즈핑크 계열)으로 할게요"
5. **텔레그램 봇 토큰** (선택) — "카드를 폰으로 받아보시려면 텔레그램 봇이 필요한데, 지금 만드실까요, 나중에 하실까요?"
   - 지금 만들겠다고 하면: 텔레그램 앱에서 `@BotFather` 검색 → `/newbot` → 이름 정하기 → 나온 토큰 붙여넣기, 순서를 하나씩 안내하며 기다린다.
   - 나중에 한다고 하면: "텔레그램 없이도 됩니다. 만든 카드는 `output` 폴더에 그대로 저장돼요"라고 안심시키고 건너뛴다.
6. **인스타 자동 업로드 여부** — "텔레그램에서 [올리기] 버튼 누르면 인스타에 자동으로 올라가게 할까요? 계정 정지 위험이 아주 약간 있어서, 원치 않으시면 꺼둘게요" (기본값 false 권장)

## 4. 파일 작성

수집한 값을 `config.json`에 쓴다. 기존에 이미 값이 채워져 있으면(재실행 상황) **함부로 덮어쓰지 말고** "이미 입력된 정보가 있는데, 새로 입력하시겠어요, 아니면 그대로 둘까요?"라고 먼저 물어본다.
작성 후 텔레그램 토큰 등 비밀값은 마스킹해서 "이렇게 저장했어요"라고 확인받는다.

## 5. Claude 로그인 확인

이미 `claude` 명령이 동작하고 있다는 건 로그인이 되어 있다는 뜻이다. 별도 조치 불필요 — README의 "2단계 클로드 로그인"은 학생이 처음 Claude Code를 설치할 때 이미 거친 단계이므로 이 스킬에서는 재확인만 하고 넘어간다.

## 6. 사진 넣기 안내

`assets/photos/`, `assets/photos-personal/` 폴더를 열어보라고 안내:
- `photos/`: 얼굴 없는 샵/도구/인테리어 사진 6~10장
- `photos-personal/`: 원장님 얼굴 나온 사진 3~6장

사진은 스킬이 대신 넣어줄 수 없으니, 넣고 나서 다시 말해달라고 요청하고 잠시 대기한다.

## 7. 테스트 실행

```bash
bash scripts/run.sh --force
```
1~2분 걸린다고 미리 알려준다. 완료되면:
- `output` 폴더에 새 카드 이미지가 생겼는지 확인
- 텔레그램을 연결했다면 봇으로 카드가 왔는지 확인해달라고 요청
성공하면 "카드가 나왔으면 성공이에요 🎉 이제 매일 아침 9시 10분에 자동으로 돌아가요"라고 마무리한다.

## 8. 트러블슈팅 (에러 신고 시 이 표로 진단)

| 증상 | 원인/조치 |
|---|---|
| npm install 실패 | 인터넷 연결 확인 후 재시도 |
| "Node.js가 없습니다" | nodejs.org에서 LTS 설치 안내 |
| 테스트해도 카드가 안 나옴 | 블로그에 최근 글이 있는지 확인 (새 글 없으면 정상적으로 스킵됨) |
| 텔레그램에 카드가 안 옴 | 봇과 대화를 한 번이라도 나눴는지(예: "안녕" 전송) 확인 |
| 폴더를 다른 곳으로 옮긴 뒤 안 됨 | `설치.command`를 한 번 더 실행하도록 안내 (launchd 등록 경로가 재설정됨) |
| 그 외 | 에러 메시지 전문을 보여달라고 요청해 원인을 함께 분석 |
