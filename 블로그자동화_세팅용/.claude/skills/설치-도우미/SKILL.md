# 설치-도우미 (블로그 자동화)

수강생이 이 폴더 안에서 Claude Code를 열고 "설치해줘" 같은 말을 하면, README.md를 읽으라고 하지 말고 **아래 순서를 직접 실행**한다. 매 단계 끝나면 다음으로 넘어가기 전에 결과를 짧게 보고한다.

## 0. 안전 원칙 (항상 지킬 것)

- **반드시 이 스킬 폴더의 조상 폴더(블로그자동화_세팅용) 안에서만** 명령을 실행한다. 시작 전 `pwd`로 위치를 확인한다.
- `~/nailblog-app`, 다른 학생의 폴더, 시스템 폴더 등 이 키트 밖은 **절대** 건드리지 않는다.
- 학생이 입력하는 클로드 토큰·Pexels 키 등 비밀값은 **이 폴더의 `.env`에만** 쓴다. 채팅에 되짚어 보여줄 때는 앞 일부만 남기고 마스킹한다.
- 이 도구는 카드뉴스와 달리 **조용히 혼자 돌지 않는다** — 대시보드를 열고 버튼을 눌러야 동작한다는 걸 학생에게 미리 알려준다.
- 어떤 단계든 실패하면 원인과 해결법을 바로 말해주고 멈춘다.

## 1. 사전 확인

```bash
node -v
command -v claude && claude --version
```
Node.js 없으면 nodejs.org LTS 설치 안내 후 멈춘다.

## 2. 패키지 설치

이 키트 폴더 안에서:
```bash
npm install --silent
npx playwright install chromium
```
실패 시 에러 메시지를 보여주고 인터넷 연결부터 확인하도록 안내.

## 3. .env 파일 준비

`.env` 파일이 없으면 `.env.example`을 복사해서 만든다.

## 4. 클로드 인증 (이 키트에서 가장 손이 가는 단계 — 특히 친절하게)

1. "터미널에서 클로드 인증 열쇠를 하나 받을게요"라고 안내
2. 이 스킬(Claude Code) 자체가 이미 로그인되어 있으므로, Bash로 직접 실행:
   ```bash
   claude setup-token
   ```
3. 브라우저가 열리면 로그인 → 허용을 안내하고, 터미널에 출력되는 토큰을 받아온다.
4. `.env`의 `CLAUDE_CODE_OAUTH_TOKEN=` 뒤에 그 값을 써넣는다.
5. **`ANTHROPIC_API_KEY`는 절대 건드리지 않는다** — 학생이 이 이름을 언급하면 "그건 넣지 않는 게 맞아요, 넣으면 구독 대신 별도 과금돼요"라고 안내한다.

## 5. 정보 수집 (한 번에 하나씩)

1. **Pexels API 키** — "무료 사진 API 키가 필요한데, https://www.pexels.com/api/ 에서 이메일로 가입하면 1분 안에 나와요. 발급되면 알려주세요" — 링크를 안내하고 기다린다.
2. **네이버 블로그 아이디** — "blog.naver.com/OOO 라면 OOO만 알려주세요"

받은 값을 `.env`에 써넣는다. 이미 값이 있으면(재실행 상황) 함부로 덮어쓰지 말고 먼저 확인한다.

## 6. 실행 & 네이버 로그인

```bash
bash 실행.command   # 또는 학생 OS에 맞는 파일
```
백그라운드 실행이 필요하면 안내만 하고, 학생이 직접 더블클릭하게 유도해도 된다(터미널을 계속 점유하는 프로세스라 스킬이 대신 띄운 채로 대화를 이어가기 애매하면 "이제 `실행.command`를 더블클릭해서 열어보세요"로 안내 전환).

브라우저가 열리면:
- **[네이버 로그인]** 클릭 → **학생이 직접** 아이디/비밀번호 입력 (절대 스킬이 대신 입력하지 않는다 — 이건 봇 탐지 방지를 위해 의도된 설계다)
- 로그인 완료되면 세션이 자동 저장됨

## 7. 테스트

- 대시보드에 키워드를 하나 넣고 [글감 찾기] → 카드 클릭 → 미리보기가 뜨는지 확인해달라고 요청
- 성공하면 "여기까지 되면 준비 끝났어요! 처음 발행할 땐 꼭 '비공개'로 먼저 올려보고 확인하세요"라고 마무리

## 8. 트러블슈팅 (에러 신고 시 이 표로 진단)

| 증상 | 원인/조치 |
|---|---|
| npm install 실패 | 인터넷 연결 확인 후 재시도 |
| "포트 3000이 이미 사용 중" | `실행.command`가 자동 정리함, 안 되면 컴퓨터 재시작 안내 |
| 브라우저가 자동으로 안 열림 | `localhost:3000` 직접 입력하도록 안내 |
| "클로드 인증이 필요해요" 계속 뜸 | 4단계(`claude setup-token`)를 다시 진행 |
| 네이버 로그인 창이 안 뜸 | 대시보드 새로고침 후 다시 [네이버 로그인] 클릭 |
| 발행 실패 | 네이버가 화면 구조를 바꿨을 수 있음 — `src/naver/selectors.json`을 손볼 문제이므로, 학생 수준을 넘는 이슈면 화면 캡쳐 요청 후 원장님께 전달 안내 |
| 자동 실행 시각이 됐는데 아무 일도 안 일어남 | 대시보드 창이 그 시각에 켜져 있었는지 확인 — 꺼져 있었으면 정상(그 시각엔 서버가 죽어있어 작동 못 함) |
| 검은 창을 실수로 닫음 | `실행.command`(또는 `.bat`) 다시 더블클릭하면 이어서 됨 |
