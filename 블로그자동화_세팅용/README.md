# 블로그 글 하나로 → 초안까지 뚝딱 — 설치 안내서

**컴퓨터를 잘 몰라도 괜찮습니다.**
이 안내서는 명령어를 한 줄도 안 치는 걸 목표로 만들었어요.
파일을 더블클릭하는 것만 하시면 됩니다.

---

## 이게 뭘 해주나요

키워드 하나만 넣으면, 컴퓨터가 알아서 이렇게 합니다.

```
키워드 입력 (예: 손톱 영양)
      ↓
네이버 뉴스·인기 블로그·논문을 다 찾아봄
      ↓
글감 5개를 골라서 보여줌
      ↓
마음에 드는 거 클릭
      ↓
본문이 써지고 사진도 알아서 붙음
      ↓
내가 읽어보고 [발행] 버튼을 누르면
      ↓
네이버 블로그에 올라감
```

원장님이 하실 일은 **키워드 하나**와 **클릭 몇 번**입니다.

> **⚠️ 카드뉴스 자동화랑 다른 점 하나만 꼭 기억해 주세요.**
> 카드뉴스는 컴퓨터가 매일 아침 혼자 알아서 돕니다.
> 이 프로그램은 **화면을 열고 버튼을 눌러야** 움직여요.
> "매일 아침 저절로 글이 올라간다"가 아니라, "화면 켜고 몇 번 클릭하면 5분 만에 초안이 나온다"에 가깝습니다.

---

# 0단계 · 먼저 아셔야 할 것 네 가지

## ① Claude(클로드)가 뭔가요

**글을 써주는 AI입니다.** 챗지피티 같은 거예요.

우리는 그중에서도 **Claude Code(클로드 코드)** 라는 걸 씁니다.
이건 좀 달라요. 대화창이 아니라 **원장님 컴퓨터 안에서 일을 하는** 클로드입니다.

**무섭게 생겼지만 무서운 거 아닙니다.**
검은 화면(터미널)이 뜨는데, 원장님이 거기에 뭘 치실 일은 딱 두 번뿐이에요 (2단계에서 설명).

## ② 돈이 듭니다 ★ 이건 꼭 알고 시작하세요

**클로드는 유료입니다. 한 달에 약 $20(미국 돈)입니다.**
우리 돈으로 3만원 좀 안 돼요.

**이게 없으면 아무것도 안 돌아갑니다.** 설치를 해도 소용없어요.
수강료에 포함돼 있지 않습니다. 원장님이 따로 결제하시는 겁니다.

**해외결제라 카드가 막힐 수 있어요.**
- 카드사 앱에 들어가서 **"해외결제 허용"** 을 켜두세요
- 그래도 안 되면 다른 카드로 해보세요
- 그래도 안 되면 단톡방에 말씀해 주세요

## ③ 컴퓨터가 켜져 있어야 합니다

이건 **원장님 컴퓨터에서 도는 프로그램**이에요. 인터넷 어딘가에 있는 게 아닙니다.

**필요한 것 정리**

- [ ] 노트북이나 데스크탑 (맥·윈도우 둘 다 됩니다. 폰만으로는 안 돼요)
- [ ] 클로드 유료 구독 (월 $20)
- [ ] 네이버 블로그 계정 (아이디·비밀번호를 원장님이 직접 입력합니다)
- [ ] 5분이면 되는 무료 사진 API 키 (4단계에서 발급)

## ④ 네이버 로그인은 제가 대신 안 합니다 (일부러요)

이 프로그램은 원장님 네이버 아이디·비밀번호를 **자동으로 입력하지 않습니다.**
프로그램이 대신 로그인하면 네이버가 "봇"으로 의심해서 캡차가 뜨거나 계정이 잠길 수 있어요.

그래서 브라우저 창이 뜨면 **원장님이 직접** 아이디·비밀번호를 치시게 만들었습니다.
한 번 로그인하면 그다음부터는 자동으로 기억해요. 매번 치실 필요 없습니다.

# 1단계 · 설치하기

## 윈도우를 쓰신다면 — 이것부터 하세요 ★

압축을 **풀기 전에** 해야 합니다. 순서가 중요해요.

1. 받으신 **zip 파일에 오른쪽 클릭**
2. **속성** 클릭
3. 맨 아래 **"차단 해제"** 에 체크
4. **확인**
5. 그다음에 압축 풀기

이걸 안 하시면 윈도우가 "위험한 파일"이라고 막습니다.

> 압축을 풀 때는 꼭 **"압축 풀기"** 를 쓰세요.
> zip 안에서 파일을 바로 더블클릭하면 안 됩니다.

## 설치 파일 더블클릭

| 쓰시는 것 | 더블클릭할 파일 |
|---|---|
| 맥 | `설치.command` |
| 윈도우 | `설치.bat` |

검은 창이 뜨고 글자가 주르륵 올라갑니다. **정상입니다.**
처음엔 5~10분쯤 걸려요. **그동안 창을 닫지 마세요.**

## 맥에서 "확인되지 않은 개발자" 가 뜨면

한 번은 뜹니다. 처음 한 번만요.

**맥 사양이 최신(세쿼이아 이상)이면**
1. 시스템 설정 열기
2. **개인정보 보호 및 보안** 클릭
3. 아래로 쭉 내리기
4. **"그래도 열기"** 버튼 클릭

**그 아래 사양이면**
1. `설치.command` 에 **오른쪽 클릭**
2. **열기** 클릭
3. 다시 뜨는 창에서 또 **열기**

## 윈도우에서 파란 창이 뜨면

"Windows의 PC 보호" 라고 나오면
**추가 정보** → **실행** 을 누르시면 됩니다.

# 2단계 · 클로드 인증 (여기가 이번 프로그램에서 제일 손이 가는 부분이에요)

설치가 끝나면 `.env` 라는 설정 파일이 자동으로 하나 생겨요.
여기에 딱 두 가지만 채우면 됩니다. 순서대로 해주세요.

## ① 클로드 열쇠(토큰) 받기

1. 검은 화면(터미널)을 하나 여세요
   - 맥: `설치.command` 를 실행했던 그 폴더에서, `테스트.command` 처럼 아무 `.command` 파일이나 열면 검은 창이 뜹니다. 또는 **Spotlight(⌘+Space)** 에 "터미널" 검색해서 여세요.
   - 윈도우: 폴더 안 빈 곳에서 **Shift + 오른쪽 클릭** → **여기에 PowerShell 창 열기**
2. 이렇게 치고 엔터:
   ```
   claude setup-token
   ```
3. 브라우저가 열리면 로그인 → **허용** 클릭
4. 터미널로 돌아오면 **길고 이상한 글자 덩어리**가 나옵니다. 이게 열쇠예요.
5. 그 글자를 **통째로 마우스로 긁어서 복사**(맥 `Cmd+C`, 윈도우 `Ctrl+C`)하세요.

## ② `.env` 파일에 붙여넣기

1. 폴더 안의 **`.env`** 파일을 메모장(윈도우) 또는 텍스트 편집기(맥)로 여세요
2. `CLAUDE_CODE_OAUTH_TOKEN=` 뒤에 방금 복사한 열쇠를 붙여넣으세요
3. 저장하고 창을 닫으세요

> **⚠️ 절대 넣으면 안 되는 것**
> `ANTHROPIC_API_KEY` 라는 칸은 **절대 채우지 마세요.**
> 여기에 뭘 넣으면 구독료 대신 **사용한 만큼 별도로 돈이 청구**됩니다.
> (프로그램이 실수로 넣여도 자동으로 걸러내긴 하지만, 그래도 넣지 않는 게 제일 안전해요.)

# 3단계 · 내 정보 넣기 (아까 그 `.env` 파일에 이어서)

같은 `.env` 파일에 아래 두 개도 채워주세요.

## ① 사진 API 키 (Pexels) — 5분, 무료, 카드번호 필요 없음

텔레그램 봇 만드는 것보다 훨씬 쉬워요.

1. https://www.pexels.com/api/ 접속
2. 이메일로 가입 (1분)
3. 발급된 키를 복사
4. `.env` 파일의 `PEXELS_API_KEY=` 뒤에 붙여넣기

> 이 키가 없어도 돌아가긴 하는데, 사진 품질이 눈에 띄게 떨어져요. 꼭 넣어주세요.

## ② 내 블로그 아이디

| 내 블로그 주소 | `.env` 에 넣을 것 |
|---|---|
| `blog.naver.com/mynailshop` | `NAVER_BLOG_ID=mynailshop` |

`.env` 파일의 `NAVER_BLOG_ID=` 뒤에 아이디만 넣으시면 됩니다.

파일을 저장하고 닫으세요. 이제 정보 입력은 끝입니다.

# 4단계 · 실행하고 네이버 로그인하기

**`실행.command`** (윈도우는 `실행.bat`) 를 더블클릭하세요.

몇 초 뒤 브라우저가 자동으로 열리면서 대시보드 화면이 나옵니다.
(안 열리면 주소창에 `localhost:3000` 을 직접 쳐보세요.)

우측 상단 **[네이버 로그인]** 버튼을 누르세요.

1. 새 브라우저 창이 뜹니다
2. **원장님이 직접** 네이버 아이디·비밀번호를 입력하세요
3. 로그인되면 창이 자동으로 닫히고, "로그인됨"으로 바뀝니다

한 번만 하면 됩니다. 다음부터는 자동으로 로그인된 상태예요.

> **이 검은 창을 닫으면 프로그램이 멈춰요.** 쓰는 동안은 그냥 켜두세요.

---

# 5단계 · 사용하는 방법

1. 대시보드 위쪽 칸에 **키워드**를 입력하고 **[글감 찾기]** 클릭 (2~4분 걸려요)
2. 나온 글감 카드 중 마음에 드는 거 **클릭** (1~2분)
   → 본문이 써지고 사진이 자동으로 붙습니다
3. **미리보기**를 확인하세요
   - 사진이 마음에 안 들면 **사진을 클릭**해서 다른 사진으로 바꿀 수 있어요
4. **[네이버에 발행]** 클릭
   → **처음엔 꼭 "비공개"로 한 번 올려서** 모양을 확인한 뒤 공개로 바꾸세요

**우측 상단 [설정]** 에서:
- **자동 실행 키워드 / 시각** — 매일 정해진 시각에 초안까지 자동으로 만들어둘 수 있어요.
  > ⚠️ 다만 이건 **이 검은 창(대시보드)이 켜져 있는 동안에만** 작동합니다. 컴퓨터를 재우거나 창을 닫으면 그 시각엔 아무 일도 안 일어나요. 카드뉴스처럼 "컴퓨터 꺼져 있어도 알아서" 는 아니라는 점, 꼭 기억해 주세요.
- **하루 발행 제한** — 기본 1건. 계정 제재를 피하려면 1~2건을 권장해요.

# 잘 안될 때

## 제일 먼저 해보실 것

**`실행.command`(또는 `.bat`) 창을 닫았다가 다시 더블클릭하세요.**
넣어둔 설정은 안 지워집니다.

## 그래도 안 되면

| 이런 상황 | 이렇게 하세요 |
|---|---|
| 브라우저가 저절로 안 열림 | 주소창에 `localhost:3000` 직접 입력 |
| "포트 3000이 이미 사용 중" | `실행.command`가 자동으로 정리해요. 그래도 안 되면 컴퓨터 재시작 |
| 네이버 로그인 창이 안 뜸 | 대시보드를 새로고침하고 [네이버 로그인] 다시 클릭 |
| "클로드 인증이 필요해요" | 2단계를 다시 하세요 (`claude setup-token`) |
| 발행이 실패함 | 네이버가 화면을 바꿔서 그럴 수 있어요 — 화면 캡쳐해서 단톡방에 올려주세요 |
| 검은 창을 실수로 닫음 | `실행.command`(또는 `.bat`) 다시 더블클릭하면 이어서 됩니다 |

## 그 외 전부

**화면을 캡쳐해서 AI에게 붙여넣고 "이거 왜 이래?" 라고 물어보세요.**

이게 진심입니다. 대부분 그걸로 풀려요.
그래도 안 되면 화면을 캡쳐해서 단톡방에 올려주세요.
